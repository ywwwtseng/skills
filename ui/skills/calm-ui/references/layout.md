# 版面與排版

Calm UI 的頁面結構、欄寬、字級層級、對齊與間距節奏。**寫任何畫面之前先讀這份**——`tokens.css` 決定每個東西長什麼樣，這份決定東西放在哪、多大、之間隔多遠。

參考的是企業級產品（ChatGPT、Claude、Linear、Notion 這一類）排版上的共通點，不是它們的外觀：
**內容收在一欄固定寬度裡、每一頁都是同一個結構、字級只有少數幾階且用途固定、間距從同一張表查。**
使用者換到哪一頁，眼睛都知道標題在哪、內容從哪裡開始、動作在哪裡。排版亂，通常就是這幾件事每一頁各做各的。

## 六條硬規則

1. **寬度只有三種。** 閱讀欄 `--column-reading`（720）、表單欄 `--column-form`（480）、全寬（資料表、分割面板）。不要為某個畫面發明 600、900、1100。
2. **每一頁同一個結構。** 頁首 → 區塊 → 區塊，見下方「頁面結構」。不要這頁標題在左上、那頁標題在卡片裡。
3. **一條左緣。** 同一欄裡標題、內文、列表、按鈕都貼齊同一條左緣。層級靠字級與間距，不靠縮排，也不靠框。
4. **一個畫面最多三種字級**（外加 caption）。第四種出現，代表層級沒想清楚，是用字級在硬撐。
5. **間距看關係，不看感覺。** 從「垂直節奏」表查。每個間距都要答得出「這兩個東西是什麼關係」；答不出來就是隨手填的數字。
6. **靠左，不置中。** 置中只給空狀態、首次使用的歡迎畫面、對話框裡的單一確認訊息。

## 頁面結構

每一個畫面都是這個骨架，只是區塊數量不同：

```
┌──── 閱讀欄 720 ─────────────────────────────┐
│                                            │  ↑ --space-8（桌面）/ --space-5（行動）
│ 頁標題                          [主要動作] │  title 24 / semibold
│ 一句話說明現況或這頁的用途                 │  body / secondary        ↕ --space-2
│                                            │
│                                            │  ↕ --space-7
│ 區塊標題                        查看全部 → │  heading 18 / semibold
│                                            │  ↕ --space-3
│ 內容（列表、段落、欄位）                   │
│                                            │
│                                            │  ↕ --space-7
│ 區塊標題                                   │
│                                            │
│ 內容                                       │
└────────────────────────────────────────────┘
```

- **頁首**：標題 + 一句說明 + 最多一個主要動作（和一個次要動作）。動作跟標題同一行、靠右，行動端移到說明下方或頂列。
- **區塊標題**：跟它的內容距離（`--space-3`）比跟上一個區塊的距離（`--space-7`）近得多。標題要「黏」在它下面的內容上，而不是懸在兩個區塊中間。
- **區塊標題列右側**可以放一個文字連結（「查看全部 →」），跟標題對齊同一條基線；不放圖示鈕群。
- **區塊之間不畫框、不放卡片**，靠 `--space-7` 的留白分開；真的需要更強的分隔，用一條 `--color-border` 橫線，不要加底色。
- **首頁**的頁首可以用 `--font-size-display`（32）的問候取代頁標題；其他頁一律 `--font-size-title`（24）。

## 排版

### 字級的用途是固定的

| token | 值 | 只用在 | 字重 |
|---|---|---|---|
| `--font-size-display` | 32 | 首頁問候、首次使用的歡迎畫面。一個產品裡出現的地方用一隻手數得完 | 600 |
| `--font-size-title` | 24 | 頁標題。一頁只有一個 | 600 |
| `--font-size-heading` | 18 | 區塊標題、詳情頁裡的段標題 | 600 |
| `--font-size-body` | 16 | 內文、列表項目的標題（用 500 區分）、表單欄位 | 400 / 500 |
| `--font-size-small` | 14 | 說明、中繼資訊、側欄列、表格內容、設定列的值、設定的分組標題（500） | 400 / 500 |
| `--font-size-caption` | 13 | 時間、狀態標記、欄位說明、提示小字 | 400 |

- 一個畫面挑其中三種，加上 caption。列表畫面通常是 title / body / small；詳情頁是 title / heading / body。
- **字重只用 400 / 500 / 600**，而且 600 只給標題。內文裡要強調，優先改語序讓重點放前面；真的要加粗，一段最多一處。
- **顏色只分三階**：`--color-text`（標題、主要內容）/ `--color-text-secondary`（說明、中繼資訊）/ `--color-text-muted`（時間、提示、已完成）。層級先用字級分，字級分不開才用顏色。

### 行長與行高

- 內文一行約 **35–45 個中文字**（英文 60–75 字元）。閱讀欄 720 在 16px 下剛好落在這個範圍——這就是欄寬固定的理由。
- 內文行高 `--line-height-normal`（1.55）；Agent 寫的長段敘述用 `--line-height-relaxed`（1.7）；標題 `--line-height-tight`（1.25）。
- 段落之間 `--space-4`（約一行高）。不要用空行或 `<br>` 撐間距。

### 對齊

- 文字一律靠左、右邊不齊（ragged right）。不要用兩端對齊——介面文字短，兩端對齊會把字距拉得忽大忽小。
- **數字**：用等寬數字（`font-variant-numeric: tabular-nums`）；在欄裡上下排列的金額、數量、百分比靠右對齊，小數位數一致。
- **列尾的狀態與時間**靠右對齊，跟列的第一行文字同一條基線。
- 圖示與文字垂直置中對齊，不是頂端對齊。

### 截斷與換行

- 標題、側欄列、列表標題：一行，超出以「…」截斷，完整內容放 tooltip 或詳情頁。
- 說明文字：最多兩行（line-clamp），不要讓一列的高度被說明撐到三四行。
- **不截斷**：金額、數量、狀態、錯誤訊息、使用者要照著做的指示。放不下就換行或重排版面。
- 按鈕文字不換行；放不下代表文字太長，改短。

### 中文排版

- 中文與英文、數字之間加半形空格：「已完成 3 項」「同步到 Google 日曆」。
- 用全形標點；句尾不加句號的地方（標題、按鈕、列表標題）整個產品一致不加。
- 數字與單位：`80%`、`10 分鐘前`、`NT$ 1,200`，千分位一律加。

## 間距

### 垂直節奏

間距一律從這張表查。表上沒有的關係，找最接近的那一列，不要自己挑數字。

| 關係 | token | 值 |
|---|---|---|
| 圖示 → 旁邊的文字 | `--space-2` | 8 |
| 上下文（時間、對象）→ 標題 | `--space-1` | 4 |
| 標題 → 說明 | `--space-2` | 8 |
| 說明 → 項目內的動作 | `--space-3` | 12 |
| 區塊標題 → 區塊內容 | `--space-3` | 12 |
| 設定的分組標題 → 第一列 | `--space-2` | 8 |
| 設定組 → 設定組 | `--space-6` | 32 |
| 段落 → 段落、清單項 → 清單項 | `--space-4` | 16 |
| 欄位 → 欄位 | `--space-5` | 24 |
| 項目 → 項目（Feed、有分隔線的清單） | `--space-6` | 32 |
| 頁首 → 第一個區塊、區塊 → 區塊 | `--space-7` | 48 |
| 頁面頂端 → 頁首（桌面） | `--space-8` | 64 |

判準只有一句：**屬於同一件事的東西，距離要明顯小於它跟下一件事的距離。** 標題離內容比離上一個區塊遠，眼睛就會把標題歸錯組。

### 水平

- 左右留白 `--space-gutter`：compact 20、expanded 以上 32。
- 列的左右內距 `--space-3`，讓 hover 底色有呼吸空間，但文字仍對齊欄的左緣（列本身往外延伸 `--space-3`）。
- 同一列裡的元素間距：圖示與文字 8、文字與列尾資訊至少 16。

## 骨架與斷點

### 斷點

| 斷點 | 寬度 | 主導航 | 頂列 |
|---|---|---|---|
| compact | < 640 | 3–4 個目的地用底部 tab bar；其餘放進從左滑出的抽屜 | 52，左邊是選單或返回 |
| medium | 640–1023 | 側欄預設收起，點選單鈕以覆蓋方式展開 | 56 |
| expanded | ≥ 1024 | 側欄常駐 `--sidebar-width`（260），可收合 | 56 |
| wide | ≥ 1440 | 同上；分割面板可以並排 | 56 |

**視窗再寬，內容也待在閱讀欄裡。** 多出來的寬度是留白，不是拿來塞第二欄 widget。

### 桌面

```
┌─────────────┬────────────────────────────────────────────┐
│ 側欄 260    │ 頂列 56   標題                     動作 ⋯  │
│             ├────────────────────────────────────────────┤
│ 主要動作    │                                            │
│             │        ┌──── 閱讀欄 720 ────┐              │
│ 首頁        │        │ 頁首               │              │
│ 任務        │        │                    │              │
│ 探索        │        │ 區塊               │              │
│             │        │                    │              │
│ 最近 / 釘選 │        │ 區塊               │              │
│   …         │        └────────────────────┘              │
│ ─────────   │                                            │
│ 帳號        │                                            │
└─────────────┴────────────────────────────────────────────┘
```

### 行動

```
┌──────────────────────────┐
│ ☰   標題              ⋯  │  頂列 52
├──────────────────────────┤
│ 頁首                     │  左右 gutter 20
│                          │
│ 區塊                     │
│                          │
│ 區塊                     │
│                          │
├──────────────────────────┤
│  首頁   任務   探索   我  │  tab bar 56 + safe area（只在頂層畫面）
└──────────────────────────┘
```

進到第二層畫面（詳情、編輯）時，tab bar 收起，頂列左邊換成返回。

### 側欄

- 底色 `--color-bg-secondary`，跟主區只差一階，**不畫分隔線**
- 由上而下：主要動作 → 主導航（3–4 項）→ 次要清單（最近、釘選）→ 帳號（釘在底部）
- 每列高 `--control-height`（36）、左右內距 `--space-3`、圓角 `--radius-sm`、文字 `--font-size-small`、一行截斷；hover `--color-surface-hover`，選中 `--color-surface-pressed` + `--color-text`
- 只有主要動作與主導航有 16px 圖示，次要清單不放圖示
- 分組標題用 caption + `--color-text-muted`，上方留 `--space-5`

### 頂列

- 高 `--topbar-height`，底色與主區相同，預設沒有底線；內容捲到頂列下方時才出現 `--color-border` 底線
- 左：標題（body、500、一行截斷）；右：最多兩個動作
- 頂列只有一個，固定；只有中間的內容區會捲動

## 常見畫面的排版

### 列表

```
產品會議摘要                                      已完成
我整理了三個決策與兩個待辦。                   10 分鐘前

API 文件                                     執行中 · 80%
正在產生範例
```

- 放在閱讀欄；欄位多到放不下才用全寬並改成表格
- 一列：標題（body、500）+ 一行說明（small、secondary）；列尾是狀態或時間（caption，靠右）
- 單行列高 ≥ 48，兩行 ≥ 64；hover `--color-surface-hover`、圓角 `--radius-sm`
- 列表不用分隔線（hover 底色已經分出列）；分隔線只給項目比較長、會包含動作的清單（像 Agent Feed）
- 篩選是一排文字 tab 或 chip，放在頁首下方 `--space-5`

### 表格（全寬）

- 表頭 caption、`--color-text-secondary`、500；沒有底色，下方一條 `--color-border`
- 列高 48、內容 `--font-size-small`；列與列之間一條 `--color-border`，不要斑馬紋
- 文字欄靠左、數字欄靠右；第一欄（名稱）最寬
- 表格外面不包卡片；超出寬度時在表格內水平捲動

### 詳情

- 頁首照「頁面結構」；中繼資訊一行（small、secondary），用「·」分隔
- 內容分段，段標題 heading；段與段 `--space-7`
- 「標籤 → 值」兩欄：標籤欄固定 120、`--color-text-secondary`，值靠左；compact 時改上下排

### 表單

表單是「使用者要填寫、然後送出」的畫面（建立、編輯）。只是看值、點進去改、或切換開關的，是設定列，見下一節。

- 放在表單欄（480），**靠閱讀欄左緣對齊，不置中**
- 標籤在欄位上方 `--space-2`；說明在欄位下方 `--space-1`（caption、muted）；錯誤訊息取代說明的位置，用 `--color-danger`
- 欄位高 `--control-height-lg`（44）、底色 `--color-surface`、圓角 `--radius-md`、無框線；focus 時 2px `--color-focus` 外框
- 欄位與欄位 `--space-5`；一組相關欄位與下一組 `--space-7`，組有自己的 heading
- 送出按鈕在表單最後：桌面靠左對齊欄位（跟著左緣），行動端全寬貼齊底部

### 設定與設定列

```
設定

王小明                                      ← 頁首：名稱 body 500
ming@example.com                            ←      信箱 small / secondary

帳號                                        ← 分組標題
名稱                            王小明  ›   ← 值列
登入方式                        Google  ›
時區                       Asia/Taipei  ›
依手機時區自動設定                           ← 列說明

偏好
通知                                 ( ●)   ← 開關列
外觀           [ 跟隨系統 │ 深色 │ 淺色 ]   ← 分段列

擴充
已安裝的 Mini App                    3  ›   ← 導覽列

登出                                        ← 危險列：--color-danger 文字
版本 1.4.2                                  ← caption / muted
```

**只有一種列的骨架**：左邊標題（body、400）、右邊尾端（值 / 開關 / 分段 / ›）。同一頁不要混用「標籤在上、值在下」的欄位寫法——那是表單，不是設定。

| 列的種類 | 尾端 | 點下去 |
|---|---|---|
| 值列 | 目前的值（small、`--color-text-secondary`）+ › | push 一頁或打開底部面板編輯 |
| 導覽列 | 數量或留空 + › | push 下一層設定 |
| 開關列 | switch，沒有 › | 直接切換，立刻生效，不需要儲存鈕 |
| 分段列 | 2–3 個選項的分段切換，沒有 › | 直接切換；超過 3 個選項改成值列 + 選擇頁 |
| 唯讀列 | 值，沒有 › | 不可點，也不要有 hover / 按下效果 |
| 危險列 | 沒有尾端，標題用 `--color-danger` | 先確認再執行 |

規則：

- **能點的一律有 ›（或是開關、分段），不能點的一律沒有。** 使用者只靠尾端判斷能不能點。
- **值放右邊，而且是真的值。** 「已開啟」「Google」「3」是值；「點此設定」不是值，留空就好。值太長時截斷值，不截斷標題。
- **列高**：單行 48；有列說明時說明放在列下方 `--space-1`（caption、muted），只掛在真的需要解釋的那一列，不要每列都有。
- **分組標題**：`--font-size-small`、`--font-weight-medium`、`--color-text-secondary`——比列文字小、比較淡。它離自己的第一列 `--space-2`，離上一組 `--space-6`，所以會「貼」在自己那組上。**每一組都要有標題**，包括只有一列的組；分組標題不要跟列裡的標籤長得一樣。
- **頁首是使用者本人**（名稱 + 信箱），不要把名稱、信箱拆成欄位放進第一組。可以編輯的話，頁首整塊可點、右邊 ›。
- **尾端對齊右邊界**：›、✓、開關的右緣都貼齊 `--space-gutter`，跟左邊文字的留白對稱。
- **破壞性動作（登出、刪除帳號）放在最後，是一列不是按鈕**：紅字、沒有尾端、單獨一組、按下先確認。不要做成實心按鈕——實心會讓它看起來像這頁的主要動作。
- **版本號**放在最底，caption、muted。
- **設定頁不放浮動按鈕或頂列圖示鈕**。設定是這一頁本身，不需要再有一顆「設定」。
- 桌面：左邊 180 寬的分類列 + 右邊閱讀欄內的設定列，同樣的列規則；行動端是分類清單，點進去 push 一頁。

### 空狀態

- 放在區塊內容的位置，不是整頁正中央；只有整頁都沒有內容時才置中
- 一行說明為什麼是空的（body）+ 一行接下來會發生什麼（small、secondary）；首次使用才給一個動作

### 對話與常駐輸入

對話畫面的訊息排列與輸入框規格在 `patterns.md` 的「對話」與「導航與 Agent 輸入」。排版上只要記得：它一樣放在閱讀欄裡、跟其他頁同一條左緣，不是另一套版面。

### 分割面板

- 只在 expanded 以上並排：左邊主內容縮到 `--split-conversation-min`（400）到 640，右邊面板佔其餘
- 中間一條 1px `--color-border`；面板有自己的頂列（標題 + 關閉）
- 更窄時面板以全螢幕 sheet 打開

### 覆蓋層

| 元件 | 尺寸 | 樣式 |
|---|---|---|
| 確認對話框 | 寬 `--dialog-width-sm`（480） | `--color-surface-elevated`、`--radius-lg`、內距 `--space-5`、`--shadow-overlay`；標題 heading、內文 body；按鈕列靠右，主要動作最右 |
| 內容對話框 | 寬 `--dialog-width-md`（640），高 ≤ 85vh | 同上；內容區自己捲動，標題與按鈕列固定 |
| 選單 | 寬 200–280 | `--color-surface-elevated`、`--radius-md`、內距 `--space-1`；每項高 36、small |
| 底部面板（行動） | 高 ≤ 90vh | 頂部圓角 `--radius-lg`、上方把手、`--shadow-sheet`；取代桌面的對話框與選單 |
| Toast | 寬 ≤ 400 | 桌面右下、行動在 tab bar 上方；一行文字 + 最多一個動作 |

## 尺寸

| 用途 | token | 值 |
|---|---|---|
| 小圖示鈕 | `--control-height-sm` | 32 |
| 桌面按鈕、側欄列、選單項 | `--control-height` | 36 |
| 輸入欄位、行動端按鈕 | `--control-height-lg` | 44 |
