# 設定與設定列

Calm UI 設定類畫面的排版。頁面結構、欄寬、字級與間距節奏照 `layout.md`，token 在 `tokens.css`。

設定頁是 calm-ui 裡**唯一用底色色塊把列包成一組的地方**：一組設定彼此相關、每一列又各自可點，符合「資訊真的屬於一組、需要獨立的互動狀態」。其他畫面照舊不放卡片。

**只有一種列的骨架**：〔圖示〕標題（body、400、`--color-text`）靠左，尾端（值 / ✓ / 選取圓 / 開關 / ›）靠右。同一頁不要混用「標籤在上、值在下」的欄位寫法——那是表單，不是設定。

| 列的種類 | 尾端 | 點下去 |
|---|---|---|
| 值列 | 目前的值（body、`--color-text-secondary`）+ › | push 一頁或打開底部面板編輯 |
| 導覽列 | 數量或留空 + › | push 下一層設定 |
| 開關列 | switch，沒有 › | 直接切換，立刻生效，不需要儲存鈕 |
| 單選組的列（選擇頁裡） | 選中：實心 `--color-accent` 圓 + ✓；沒選中：空心圓（1.5px `--color-text-muted`） | 點整列就選它，立刻生效 |
| 複選組的列 | 選中：`--color-accent` 的 ✓；沒選中：留空 | 點整列切換，立刻生效 |
| 唯讀列 | 值（body、`--color-text-secondary`、等寬數字），沒有 › | 不可點，沒有 hover / 按下效果；長按可複製 |
| 危險列 | 沒有尾端，標題用 `--color-danger` | 先確認再執行 |

**組的樣式**

- 組是一塊 `--color-surface` 底色、`--radius-md` 圓角、**沒有框線也沒有陰影**；組外是頁面底色 `--color-bg`，靠這一階色差分出組
- 組的左右緣貼齊 `--space-gutter`；**分組標題、組尾說明跟組的左緣對齊**，列裡的文字再往內 `--space-4`
- 列高 `--settings-row-height`（行動 52 / 桌面 48）；列的左右內距 `--space-4`
- 列與列之間一條 1px `--color-border`，橫跨整個組寬；第一列上方、最後一列下方不畫
- 按下時整列 `--color-surface-pressed`（桌面 hover 用 `--color-surface-hover`），圓角跟著組的第一列 / 最後一列
- **圖示是整組一起的決定**：一組裡要嘛每列都有前導圖示，要嘛都沒有。圖示 `--icon-size`（20）、線性、`--color-text`，跟標題距離 `--space-3`。選項本身有具體意象時才放（外觀、手勢、通知種類）；純資料的組（帳號、關於）不放

**分組標題與組尾說明**

- **分組標題**：`--font-size-heading`（18）、600、`--color-text`。它比列文字大、比列文字粗，所以一眼就分得出「這是一組的名字」而不是一列。**每一組都要有標題**，只有危險列那組例外（登出本身就說明了自己）
- **組尾說明**：放在組的**下方**，caption、`--color-text-secondary`，最多兩行。說的是整組的效果，或目前選項的後果（「跟隨系統會依裝置的外觀自動切換」）。**說明不放進組裡、不掛在個別列下面**；如果兩列各需要不同的說明，代表它們該拆成兩組
- 間距：分組標題 → 組 `--space-3`；組 → 組尾說明 `--space-2`；組（或組尾說明）→ 下一個分組標題 `--space-6`

**選項怎麼放**

- 2–5 個互斥選項（外觀、語言較少時、預設行為）：**一列值列，點下去從底部打開選項面板**（見 `interactions.md` 的「選項面板」）。不要在設定頁直接展開成單選組——一個設定佔一整組、把其他設定推出畫面；也不要做成分段切換
- 超過 5 個選項（時區、語言很多時）：值列 + push 選擇頁；選擇頁本身就是一個單選組
- 幾個可以同時開的選項（通知種類、手勢）：複選組。只有一個可開關的東西，用開關列

**其他規則**

- **能點的一律有尾端（› / ✓ / 選取圓 / 開關），不能點的一律沒有。** 使用者只靠尾端判斷能不能點。
- **值放右邊，而且是真的值。** 「已開啟」「Google」「3」是值；「點此設定」不是值，留空就好。值太長時截斷值，不截斷標題。
- **頁首是使用者本人**（名稱 + 信箱），放在所有組之前、不包進組裡。不要把名稱、信箱拆成列放進第一組，也不要在組裡再放一列「名稱」——同一個值不出現兩次。可以編輯的話，頁首整塊可點、右邊 ›。
- **尾端對齊組的右緣內 `--space-4`**：›、✓、選取圓、開關、值的右緣在同一條線上。
- **破壞性動作（登出、刪除帳號）放在最後，是一列不是按鈕**：紅字、沒有尾端、單獨一組、按下先確認。不要做成實心按鈕——實心會讓它看起來像這頁的主要動作。
- **版本號**放進最後的「關於」組當唯讀列；只有一個版本號時也可以不開組，改成頁面最底一行 caption、muted。
- **設定頁不放浮動按鈕或頂列圖示鈕**。設定是這一頁本身，不需要再有一顆「設定」。
- 字級：頁標題 title、分組標題 heading、列 body、組尾說明 caption——剛好三種加 caption，值也用 body（只換顏色），不要再加 small。
- 桌面：左邊 180 寬的分類列 + 右邊表單欄（480）寬的組，靠閱讀欄左緣；同樣的組與列規則。行動端是分類清單（本身也是一組導覽列），點進去 push 一頁。
